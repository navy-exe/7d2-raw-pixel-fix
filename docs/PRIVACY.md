# Published data

This repository contains source, patches, text logs, measurements, per-frame
hashes and two rendered before/after comparison images in `docs/images`. The
camera owner explicitly approved publication of those two images. Original
photos, videos, RAW pixel payloads and project camera ROM dumps are excluded.
Generic artwork and synthetic test fixtures already tracked in the upstream
source remain. The comparison images are derivatives of the matched lit-scene
RAW snapshots and use identical MLV App processing; they are not original RAW
files or a matched high-ISO noise test.

Some inspection records reference excluded media filenames. They document the
original local analysis, not files downloadable from this repository. Image
statistics cannot be independently recomputed without original pixels; developers
can run the experiment with their own supported-camera data. Camera serial
numbers and local drive paths are not intended for publication.
