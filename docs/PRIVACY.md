# Published data

This repository contains source, patches, text logs, measurements, per-frame
hashes and other non-image metadata. No user-shot photos, videos, original RAW
pixel payloads, preview images or camera ROM dumps are included. Generic artwork
and synthetic test fixtures already tracked in the upstream source remain.

Some inspection records reference excluded media filenames. They document the
original local analysis, not files downloadable from this repository. Image
statistics cannot be independently recomputed without original pixels; developers
can run the experiment with their own supported-camera data. Camera serial
numbers and local drive paths are not intended for publication.
